\# 🤖 AI Pathfinding Game using A\* and Q-Learning



An AI-powered grid-based game developed in Python. The player navigates to the goal using the A\* Search Algorithm, while the enemy learns to chase the player using Q-Learning Reinforcement Learning.



\## ✨ Features



\- A\* Pathfinding Algorithm

\- Q-Learning Enemy AI

\- Tkinter GUI

\- Obstacle Avoidance

\- Episode Counter

\- Win/Loss Counter

\- Start, Stop \& Restart Controls

\- Reinforcement Learning



\## 🛠️ Technologies



\- Python 3

\- Tkinter

\- NumPy



\## 📦 Installation



```bash

pip install -r requirements.txt

```



\## ▶️ Run



```bash

python AI-GameCode.ipynb

```



> Open the notebook in Jupyter Notebook or JupyterLab and run all cells.
